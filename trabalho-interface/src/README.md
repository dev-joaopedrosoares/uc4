
# O Senhor dos Mercados II

## Sobre o projeto

O Senhor dos Mercados II é um RPG de terminal
desenvolvido em TypeScript.

O jogador escolhe um herói e enfrenta inimigos
em combates por turnos até chegar ao
Servidor da Perdição.

## Personagens

- Diegolas: Arqueiro
- Samuel: Guardião
- Seu Zé: Guerreiro

## Inimigos

1. Fiscal de Preços
2. Operador de Ofertas
3. Balrog do Boleto (chefe final)

## Funcionalidades

- Menu interativo
- Escolha de personagens
- Combate por turnos
- Habilidades especiais
- Sistema de ataque e defesa
- Sistema de cura
- Progressão de inimigos
- Contador de vitórias
- Encerramento com dois finais
- Opção de jogar novamente

## Tecnologias utilizadas

- TypeScript
- Node.js
- readline-sync

## Instalação

É necessário ter Node.js e npm instalados.

Clone ou baixe o projeto e abra a pasta
no terminal.

Instale as dependências:

npm install

## Execução

Execute:

npm start
